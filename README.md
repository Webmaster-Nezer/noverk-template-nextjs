# New app (Next.js)

Started from a Noverk Web Code template. Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 and shadcn/ui components in src/components/ui, tested with Vitest and Testing Library.

## Run it
- `npm install` once, then `npm run dev` (http://localhost:3000)
- `npm test` runs the tests, `npm run lint` and `npm run typecheck` the checks
- `npm run build` makes the production build
- Add shadcn/ui components with `npx shadcn@latest add <name>`

Environment variables go in `.env` (see `.env.example`); never commit real values.
